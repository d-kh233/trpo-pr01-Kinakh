# trpo-pr01-Kinakh

Страница разработана с использованием семантических тегов HTML5 и адаптивной верстки на CSS3 без использования сторонних фреймворков. Содержит навигацию, раздел «О курсе», карточки направлений, таблицу оценок важности тем, форму регистрации с валидацией и подвал.

Технологии
    HTML5 - семантическая структура   
    CSS3 - Flexbox, базовые стили 
    Git - управление версиями

Структура HTML
body — главный контейнер 
    header — шапка: навигация (nav) и заголовок первого уровня (h1) 
        nav — меню навигации с якорными ссылками (#about, #tracks, #schedule, #signup)  
        main — основной контент страницы  
        section id="about" — раздел «О курсе»: заголовок и логотип  
        section id="tracks" — раздел «Направления»: 6 карточек (article) с темами   
            article — отдельные карточки с категориями, заголовками и описанием  
        section id="schedule" — раздел «Оценка важности тем»: таблица с данными   
        section id="signup" — раздел «Регистрация»: форма с подписями (label), инпутами разных типов, текстовым полем и кнопкой  
        footer — подвал страницы с информацией о курсе, группе и авторе  
        
        Семантика: header, nav, main, section, article, footer. 
        Иерархия заголовков: h1 → h2 → h3 → h4.  


            ==CSS-приёмы==
    box-sizing: border-box — сброс размеров элементов для корректного расчёта ширины   
    Flexbox — организация сетки карточек (flex-wrap: wrap), центрирование элементов формы и выравнивание ссылок навигации  
    Медиазапрос (@media (max-width: 768px)) — перестройка навигации в столбик и растягивание карточек на 100% ширины на мобильных устройствах   выделение фокуса (:focus, :focus-visible) с помощью outline для навигации с клавиатуры

==Проверка==
    -DevTools (F12) → Console: отсутствуют ошибки и предупреждения.   
    -Адаптивность: при ширине экрана менее 768px карточки и меню перестраиваются в вертикальный столбик без горизонтальной прокрутки.  
    -Клавиатурная навигация: при нажатии клавиши Tab интерактивные элементы (ссылки, поля ввода, кнопки) получают четкую обводку фокуса (outline).   
    -Cсылки в меню переносят к соответствующим секциям страницы.
